### Elixir

- Dependencies: `mix deps.get`
- Build: `mix compile --warnings-as-errors`
- Test: `mix test`
- Format: `mix format --check-formatted`
- Run: `iex -S mix` (Phoenix: `mix phx.server`)
- Expected layout: `mix.exs` at the root, code under `lib/`, tests under `test/` mirroring `lib/`, config under `config/`.
